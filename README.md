# PyTask

PyTask is a command-line task management application built with Python.

## Features

- Add tasks
- Remove tasks
- Edit tasks
- Mark tasks as completed or pending
- Search tasks
- Sort tasks
- Due dates
- Priority levels
- Plugin architecture
- JSON storage

## Technologies

- Python
- argparse
- dataclasses
- enum
- pytest
